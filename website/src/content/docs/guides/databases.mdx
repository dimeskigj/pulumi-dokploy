---
title: Databases
description: Provision PostgreSQL, MySQL, MariaDB, MongoDB, and Redis services with secret-aware credentials.
---

Postgres, MySQL, MariaDB, MongoDB, and Redis are resources in the target Project/Environment. Supply passwords as secret inputs and make each database depend on the Project’s default Environment or an explicit Environment through `environmentId`.

```typescript
const database = new dokploy.Postgres("app-db", {
  name: "app-db",
  environmentId: environment.environmentId,
  databaseName: "app",
  databaseUser: "app",
  databasePassword: config.requireSecret("databasePassword"),
});
```

MySQL and MariaDB use the same shape, plus an optional `databaseRootPassword`:

```typescript
const mysql = new dokploy.MySQL("app-mysql", {
  name: "app-mysql",
  environmentId: environment.environmentId,
  databaseName: "app",
  databaseUser: "app",
  databasePassword: config.requireSecret("mysqlPassword"),
  databaseRootPassword: config.requireSecret("mysqlRootPassword"),
});
```

MongoDB has no `databaseName` and instead accepts an optional `replicaSets` flag:

```typescript
const mongo = new dokploy.MongoDB("app-mongo", {
  name: "app-mongo",
  environmentId: environment.environmentId,
  databaseUser: "app",
  databasePassword: config.requireSecret("mongoPassword"),
  replicaSets: true,
});
```

Redis uses the same placement dependency and requires a password, with no database name or user:

```typescript
const cache = new dokploy.Redis("app-cache", {
  name: "app-cache",
  environmentId: environment.environmentId,
  databasePassword: config.requireSecret("redisPassword"),
});
```

The `environmentId` and optional `serverId` control placement and are replacement-only; database names, images, ports, and environment values are runtime configuration that updates the service. Passwords (including `databaseRootPassword`) are write-only secret inputs: they are not returned during refresh and may need to be restored after import. Database environment values are secret inputs; do not log them. Review the [Postgres reference](../../reference/postgres/), [MySQL reference](../../reference/mysql/), [MariaDB reference](../../reference/mariadb/), [MongoDB reference](../../reference/mongodb/), [Redis reference](../../reference/redis/), [imports guide](../imports/), and [secrets guidance](../../concepts/secrets/).
