title: Examples
description: Complete Pulumi Dokploy examples in six languages.

The [Complete Example](./complete/) shows the canonical YAML program alongside the tracked TypeScript, Python, Go, C#, and Java programs. `make gen_examples` converts canonical YAML into those tracked language programs; the website generator embeds the tracked files without translating them.

The repository versions are available in the [YAML example](https://github.com/gjorgjidimeski/pulumi-dokploy/tree/main/examples/yaml), [TypeScript example](https://github.com/gjorgjidimeski/pulumi-dokploy/tree/main/examples/nodejs), [Python example](https://github.com/gjorgjidimeski/pulumi-dokploy/tree/main/examples/python), [Go example](https://github.com/gjorgjidimeski/pulumi-dokploy/tree/main/examples/go), [.NET example](https://github.com/gjorgjidimeski/pulumi-dokploy/tree/main/examples/dotnet), and [Java example](https://github.com/gjorgjidimeski/pulumi-dokploy/tree/main/examples/java) directories.

Placeholders are intentionally invalid. Before running an example, supply the endpoint and credentials with secret configuration; never commit real secrets.
