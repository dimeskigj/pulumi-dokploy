---
title: First deployment
description: Configure Dokploy and deploy a first application with Pulumi.
---

Set the endpoint and API key in the stack. The API key is secret configuration and should come from your shell or a secret manager, not source control.

```bash
pulumi config set dokploy:endpoint https://dokploy.example.com
pulumi config set --secret dokploy:apiKey "$DOKPLOY_API_KEY"
```

Create a project and Docker-backed application. The `Project` owns its default production environment, so the application can target `project.defaultEnvironmentId`.

```typescript
import * as dokploy from "@dimeskigj/pulumi-dokploy";

const project = new dokploy.Project("platform", { name: "platform" });
const app = new dokploy.Application("web", {
  name: "web",
  environmentId: project.defaultEnvironmentId,
  source: { type: "docker", docker: { image: "nginx:latest" } },
});
```

Run `pulumi up`. The provider creates the Dokploy objects and waits until the deployment reports completion. Confirm the application and its deployment in Dokploy before proceeding.

When the environment is disposable, run `pulumi destroy`. Compose volumes are retained by default; see the [Compose guide](../../guides/compose/).
