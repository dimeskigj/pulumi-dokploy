---
title: Contributing
description: Validate, generate, and improve the Pulumi Dokploy provider documentation.
---

Install the pinned toolchain and dependencies:

```bash
mise install
```

Run provider checks before opening a change:

```bash
make lint
make test
make build
make check_openapi
```

For documentation, regenerate references and examples, then run the full checks:

```bash
make docs_generate
make docs_check
```

Schema-generated reference pages and generated examples are owned by their generators; update the schema or generator rather than hand-editing generated files. The Pages workflow builds the static site only after checks pass and publishes the `website/dist` artifact. Curated lifecycle explanations belong in the guides and concepts pages, outside `reference/`.
