## Provider guarantees

<CardGrid stagger>
	<Card title="Plan before you apply" icon="magnifier">Pulumi previews show planned changes before Dokploy is modified.</Card>
	<Card title="Deployment-aware writes" icon="clock">Creates and updates wait for Dokploy deployment completion.</Card>
	<Card title="Stays in sync" icon="random">Imports and refreshes reconcile existing Dokploy resources with Pulumi state.</Card>
	<Card title="Recoverable failures" icon="warning">Deployment errors retain partial state and the resource ID for repair.</Card>
	<Card title="Secrets stay secret" icon="padlock">Secret inputs and derived secret outputs remain redacted and are never logged.</Card>
</CardGrid>
