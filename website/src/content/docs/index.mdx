## Provider guarantees

- Pulumi previews show planned changes before Dokploy is modified.
- Creates and updates wait for Dokploy deployment completion.
- Imports and refreshes reconcile existing Dokploy resources with Pulumi state.
- Deployment errors retain partial state and the resource ID for repair.
- Secret inputs and derived secret outputs remain redacted and are never logged.
